# 📝 День 1 — Базовое приложение FastAPI (план решения)

## 🎯 Цель
Поднять минимальное работающее приложение FastAPI с одним эндпоинтом
`GET /`, который возвращает `{"message": "ml churn service is running"}`,
и убедиться, что сервис отвечает.

Это первый шаг 14-дневного проекта `fastapi_churn`. В дальнейшем сюда же
будут добавляться Pydantic-модели (день 2), предобработка, обучение модели,
предсказания и т.д. Поэтому структуру делаем простой, но аккуратной.

## ⚙️ Как будет работать решение

1. **`main.py`** — точка входа:
   - создаём объект приложения `app = FastAPI(title="ML Churn Service")`;
   - объявляем один маршрут `GET /` через декоратор `@app.get("/")`;
   - обработчик возвращает Python-словарь
     `{"message": "ml churn service is running"}`.
     FastAPI автоматически сериализует его в JSON и проставляет
     заголовок `Content-Type: application/json`.

2. **Запуск** через ASGI-сервер uvicorn:
   `uvicorn main:app --reload`
   - `main` — имя файла без `.py`;
   - `app` — имя объекта FastAPI внутри файла;
   - `--reload` — авто-перезапуск при изменении кода (удобно в разработке).
   - Сервер слушает `http://127.0.0.1:8000`.

3. **Проверка** — три способа:
   - браузер: `http://127.0.0.1:8000/` → видим JSON с сообщением;
   - Swagger UI: `http://127.0.0.1:8000/docs` (FastAPI генерирует сам);
   - консоль: `curl http://127.0.0.1:8000/`.

## 🪜 Пошаговый план реализации

1. **Окружение.** Создать виртуальное окружение (Python 3.11 уже есть):
   `python3 -m venv .venv && source .venv/bin/activate`.
   *(venv в корне проекта или внутри папки дня — уточнить при реализации.)*
2. **Зависимости.** Записать в `requirements.txt`:
   ```
   fastapi
   uvicorn[standard]
   ```
   и установить: `pip install -r requirements.txt`.
3. **Код.** Написать `main.py` (≈6 строк: импорт, `app`, эндпоинт).
4. **Запуск.** `uvicorn main:app --reload` из папки `homework/1_day/`.
5. **Проверка.** Открыть `/` и `/docs`, убедиться в корректном ответе.
6. **README.** Зафиксировать команды установки и запуска.
